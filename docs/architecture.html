Architecture de DARCUS Agent

Un agent IA en Python : une boucle ReAct pilotée par un LLM local, des agents de fond qui maintiennent la mémoire, et une API FastAPI qui l'expose aux clients web et mobile.

Modules

CheminRôle
main.pyPoint d'entrée : console, ou serveur avec --api.
jan_agent/core.pyClasse JanAgent : contexte, classification, boucle ReAct, exécution sécurisée des commandes, streaming.
jan_agent/planner.pyGénère un plan d'étapes avant l'exécution.
jan_agent/react_parser.pyLit les blocs thought, call et response produits par le LLM.
jan_agent/agents/Agents de fond (BackgroundAgent, un thread chacun) et agents spécialisés à prompt propre : Conversation, Coding, Research, Critic.
jan_agent/runtime.pyAgentRuntime : démarre et arrête les cinq agents de fond.
jan_agent/tools/Registre d'outils (décorateur @tool) et outils de base ; custom_tools/ est chargé dynamiquement.
jan_agent/database.pyPersistance SQLite : conversations, plans, tâches, métriques, règles de sécurité, modèles ML.
jan_agent/api/Routes REST et SSE, authentification JWT, schémas Pydantic.
ml_models/Cycle de vie des modèles scikit-learn : entraînement, versions, évaluation, prédiction, routes /api/models.
pr_generator/Générateur de données et tableau de bord Streamlit, sur PostgreSQL.
config.jsonServeur et modèle LLM, seuils de mémoire, règles de sécurité, prompt système.

Parcours d'un message en mode API

  1. Le client envoie le message à /api/v2/chat/send avec son jeton JWT, vérifié avant tout traitement.
  2. JanAgent classifie la requête (heuristique, sinon appel LLM) : conversation, coding ou research. L'agent retenu fournit son prompt, surchargeable dans config.json.
  3. La boucle ReAct appelle le LLM : celui-ci répond ou demande un outil.
  4. Le registre exécute l'outil ; l'observation retourne au LLM jusqu'à la réponse finale. Pour du code, le critic-agent relit la réponse et signale les défauts ou failles.
  5. La réponse arrive au client en flux (SSE) et l'échange est enregistré dans SQLite.
  6. En parallèle, Memory résume les longues conversations et Performance publie ses métriques.
